# 家用电脑配置指南

> **背景**：公司电脑已完成项目初始化与同步配置。家里电脑按本文档配置后，即可与公司电脑**同步开发**（代码 + Claude Code 对话记录 + VSCode 设置）。
>
> 两台电脑通过 GitHub 仓库中转同步，**无需直连、无需同时在线**。
>
> ⚠ **重要**：国内访问 GitHub 的 HTTPS（443 端口）不稳定，本指南**全程使用 SSH 协议**（22 端口，更稳定）。

## 仓库地址（SSH）

| 仓库 | SSH 地址 | 用途 |
| --- | --- | --- |
| 代码（公开） | `git@github.com:qinxukun21/genealogy.git` | 项目源码 |
| 对话记录（私有） | `git@github.com:qinxukun21/claude-code-sync.git` | Claude Code 聊天历史 |

## 一、安装必要软件

- [Node.js](https://nodejs.org/) >= 18
- [Git](https://git-scm.com/)（含 Git Bash）
- [VSCode](https://code.visualstudio.com/)
- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（编译小程序时用）

> GitHub CLI（gh）非必需--本指南用 SSH，不需要 gh。

## 二、配置 git 身份

```bash
git config --global user.name "qinxukun21"
git config --global user.email "2644908936@qq.com"
```

## 三、生成 SSH 密钥并添加到 GitHub（关键！clone 前必须完成）

### 1. 生成密钥（在 Git Bash 中执行）

```bash
ssh-keygen -t ed25519 -C "2644908936@qq.com" -f ~/.ssh/id_ed25519 -N ""
```

> `-N ""` 表示不设密码，方便自动化同步。

### 2. 复制公钥

```bash
cat ~/.ssh/id_ed25519.pub
```

复制输出的整行（形如 `ssh-ed25519 AAAA... 2644908936@qq.com`）。

### 3. 添加到 GitHub

1. 打开 <https://github.com/settings/keys>
2. 点 **`New SSH key`**
3. **Title** 填 `家里电脑`，**Key** 粘贴上一步复制的公钥
4. 点 **`Add SSH key`**

### 4. 测试 SSH 连接

```bash
ssh -T git@github.com
```

看到 `Hi qinxukun21! You've successfully authenticated` 即成功。

## 四、克隆项目（务必保持相同路径！）

```bash
git clone git@github.com:qinxukun21/genealogy.git "d:/File/vscode_workplace/族谱"
cd "d:/File/vscode_workplace/族谱"
npm install
```

⚠ **路径必须与公司电脑一致**（`d:/File/vscode_workplace/族谱`）。Claude Code 按项目路径存放对话记录，路径一致才能在公司电脑的对话基础上**直接续接**；路径不同则记录分散、无法自动续接。

## 五、同步 Claude Code 对话记录到 `~/.claude`

### 情况 A：家里电脑未用过 Claude Code（`~/.claude` 不存在）

```bash
git clone git@github.com:qinxukun21/claude-code-sync.git "$HOME/.claude"
```

### 情况 B：家里电脑已用过 Claude Code（`~/.claude` 已存在）

```bash
# 1. 备份现有目录
mv ~/.claude ~/.claude.bak

# 2. 克隆同步仓库（SSH）
git clone git@github.com:qinxukun21/claude-code-sync.git "$HOME/.claude"

# 3. 恢复登录凭证（凭证不入仓库，需手动恢复）
cp ~/.claude.bak/.credentials.json ~/.claude/ 2>/dev/null

# 4. 确认正常后可删除备份
# rm -rf ~/.claude.bak
```

> **关于登录凭证**：Claude Code 的 `.credentials.json` 是**本地存储**，不入仓库（安全设计）。家里电脑首次使用 Claude Code 时需重新登录，或按上面步骤从备份恢复。

## 六、开启 VSCode Settings Sync

1. `Ctrl+Shift+P` -> 输入 **`Settings Sync: Turn On`**
2. 选 **GitHub** 登录 -> 勾选要同步的内容（设置、扩展、快捷键、代码片段）
3. 登录与公司电脑**相同的 GitHub 账号**，VSCode 配置自动同步

## 七、日常同步（双击脚本，最简单）

项目内置两个一键脚本（已随 clone 自带，**走 SSH，带网络自动重试**）：

- **`scripts\start-work.bat`** -- 开始工作时双击，拉取最新代码 + 对话记录
- **`scripts\end-work.bat`** -- 结束工作时双击，推送代码 + 对话记录

💡 **方便日常使用**：右键 `start-work.bat` -> **发送到 -> 桌面快捷方式**，以后双击桌面图标即可。`end-work.bat` 同理。

也可在 VSCode 内运行：`Ctrl+Shift+P` -> `Tasks: Run Task` -> `Start Work` / `End Work`。

## 八、日常使用流程

```text
【公司电脑结束工作】双击 end-work.bat     ← 推送代码 + 对话记录
【家里电脑开始工作】  双击 start-work.bat  ← 拉取最新
【家里电脑结束工作】  双击 end-work.bat
【公司电脑开始工作】  双击 start-work.bat
```

> 结束工作前先用 `git add -A && git commit -m "..."` 提交代码，再双击 `end-work.bat`（脚本会提示）。

## 九、验证配置是否成功

```bash
# SSH 连接
ssh -T git@github.com              # 应返回 Hi qinxukun21!

# 对话记录已同步
ls ~/.claude/projects/             # 应有 .jsonl 文件和 memory 目录
```

能看到与公司电脑相同的项目目录（如 `d--File-vscode-workplace---`）即说明同步成功。

## 十、注意事项

- ✅ 两台电脑**路径保持一致**：`d:/File/vscode_workplace/族谱`
- ✅ 两台电脑**一般不同时在线**，对话记录每个会话是独立文件，**不会冲突**
- ✅ 全程走 **SSH 协议**（22 端口），比 HTTPS 稳定
- ⚠ 网络波动时 `.bat` 会**自动重试 5 次**（每次间隔 5 秒）；持续不通需检查网络/代理
- ⚠ 若 `start-work.bat` 提示「Local has uncommitted changes」，说明本地有未提交改动，先 `git commit` 再拉取
- ⚠ Claude Code 登录是本地的，每台电脑需各自登录一次
