# 家用电脑配置指南

> **背景**：公司电脑已完成项目初始化与同步配置。家里电脑按本文档配置后，即可与公司电脑**同步开发**（代码 + Claude Code 对话记录 + VSCode 设置）。
>
> 两台电脑通过 GitHub 仓库中转同步，**无需直连、无需同时在线**。

## 仓库地址

| 仓库 | 地址 | 用途 |
|---|---|---|
| 代码（公开） | https://github.com/qinxukun21/genealogy | 项目源码 |
| 对话记录（私有） | https://github.com/qinxunkun21/claude-code-sync | Claude Code 聊天历史 |

## 一、安装必要软件

- [Node.js](https://nodejs.org/) >= 18
- [Git](https://git-scm.com/)（含 Git Bash）
- [VSCode](https://code.visualstudio.com/)
- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（编译小程序时用）
- [GitHub CLI](https://cli.github.com/)（`gh` 命令）

## 二、克隆项目（务必保持相同路径！）

```bash
git clone https://github.com/qinxukun21/genealogy.git "d:/File/vscode_workplace/族谱"
cd "d:/File/vscode_workplace/族谱"
npm install
```

⚠ **路径必须与公司电脑一致**（`d:/File/vscode_workplace/族谱`）。Claude Code 按项目路径存放对话记录，路径一致才能在公司电脑的对话基础上**直接续接**；路径不同则记录分散、无法自动续接。

## 三、配置 git 身份

```bash
git config --global user.name "qinxukun21"
git config --global user.email "2644908936@qq.com"
```

## 四、GitHub 登录

安装 gh 后**重启终端**（让 PATH 生效），然后：

```bash
gh auth login
```

按提示选择：`GitHub.com` → `HTTPS` → `Login with a web browser`，复制一次性代码到浏览器授权。

## 五、同步 Claude Code 对话记录到 `~/.claude`

### 情况 A：家里电脑未用过 Claude Code（`~/.claude` 不存在）

```bash
git clone https://github.com/qinxunkun21/claude-code-sync.git "$HOME/.claude"
```

### 情况 B：家里电脑已用过 Claude Code（`~/.claude` 已存在）

```bash
# 1. 备份现有目录
mv ~/.claude ~/.claude.bak

# 2. 克隆同步仓库
git clone https://github.com/qinxunkun21/claude-code-sync.git "$HOME/.claude"

# 3. 恢复登录凭证（凭证不入仓库，需手动恢复）
cp ~/.claude.bak/.credentials.json ~/.claude/ 2>/dev/null

# 4. 确认正常后可删除备份
# rm -rf ~/.claude.bak
```

> **关于登录凭证**：Claude Code 的 `.credentials.json` 与 `gh` 的登录态都是**本地存储**，不入仓库（安全设计）。家里电脑首次使用 Claude Code 时需重新登录，或按上面步骤从备份恢复。

## 六、开启 VSCode Settings Sync

1. `Ctrl+Shift+P` → 输入 **`Settings Sync: Turn On`**
2. 选 **GitHub** 登录 → 勾选要同步的内容（设置、扩展、快捷键、代码片段）
3. 登录与公司电脑**相同的 GitHub 账号**，VSCode 配置自动同步

## 七、自动同步功能（项目已内置）

项目已配置一键同步任务，**无需手动逐条敲命令**：

### 🌅 开始工作时 —— 自动拉取

打开 VSCode 项目文件夹时，会**自动运行** `Start Work (Pull All)` 任务，拉取最新代码和对话记录。

- 首次打开会弹窗询问是否允许自动运行任务，选 **Allow Automatic Tasks...（允许）**
- 之后每次打开项目自动拉取
- 也可手动运行：`Ctrl+Shift+P` → `Run Task` → `Start Work (Pull All)`

### 🌙 结束工作时 —— 手动推送

结束工作前运行 `End Work (Push All)`：

- `Ctrl+Shift+P` → `Run Task` → `End Work (Push All)`
- 会推送对话记录；若代码有未提交改动，会提示先 `git commit`

## 八、日常使用流程

```
【公司电脑结束工作】
  1. git add -A && git commit -m "..."
  2. 运行 End Work (Push All)   ← 推送代码 + 对话记录

【家里电脑开始工作】
  1. 打开 VSCode（自动 Start Work 拉取）
  2. 或手动运行 Start Work (Pull All)

【家里电脑结束工作】
  1. git add -A && git commit -m "..."
  2. 运行 End Work (Push All)
```

## 九、验证配置是否成功

家里电脑配置完成后，验证对话记录已同步：

```bash
# 应能看到若干 .jsonl 文件（对话记录）和 memory 目录
ls ~/.claude/projects/
```

能看到与公司电脑相同的项目目录（如 `d--File-vscode-workplace---`）即说明同步成功。

## 十、注意事项

- ✅ 两台电脑**路径保持一致**：`d:/File/vscode_workplace/族谱`
- ✅ 两台电脑**一般不同时在线**，无需担心冲突
- ✅ 对话记录每个会话是独立文件，**不会冲突**
- ⚠ 若两台同时在线并修改同一代码文件，`git pull` 可能冲突，需手动解决
- ⚠ `gh` 登录、Claude Code 登录是本地的，**每台电脑需各自登录一次**

## 十一、手动同步命令（备选）

不想用任务时，可手动执行：

```bash
# 代码
git pull            # 拉取
git push            # 推送

# 仅对话记录
bash scripts/sync-claude.sh pull
bash scripts/sync-claude.sh push

# 一键（代码 + 对话记录）
bash scripts/sync-all.sh start    # 开始工作：pull 全部
bash scripts/sync-all.sh end      # 结束工作：push 全部
```
